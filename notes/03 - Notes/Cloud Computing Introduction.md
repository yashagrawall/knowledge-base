# Cloud Computing Introduction 

- A step forward to access the web-based services through Internet 
- What helped boost : 
	- development in computing hardware, software architecture, web technology and network communications 
	- increase in speed of cheaper internet works
- Provides the means for users to easily avail computing facilities whenever and wherever required 
	- Need not worry about setting up infrastructure, purchasing new equipment or investing in the procurement of licenced software 
	- Purchase any volume of computing facilities 

---
## Limitations of Traditional Computing Approaches 

---
### Enterprise Perspective 

- To run ERP (Enterprise Resource Planning) applications, business organizations need to invest huge volumes of capital to setup the required IT infrastructure.
- Servers, client terminals, network infrastructure are required, and they to be put together in a proper manner.
- Arranging adequate power supply, cooling system and provisioning space also consume a major part of the IT budget.
- Setting up infrastructure, installation of OS, device drivers, management of routers, firewalls, proxy servers etc. are all responsibilities of the enterprise.
- Enterprises (or IT service firms) need to maintain a team of experts (system maintenance team) in order to manage the whole thing
	- This is a burden for HR management and incurs recurring capital investment (for salaries)
- IT Enterprises are bound to setup computing infrastructure before they start any development work
- Computing infrastructure requires adequte hardware procurement. 
- After every few years, existing devices become obsolete
	- Advanced software also requires upgraded  hardware 
- Adopting to updated version of an application requires necessary efforts from subscriber’s end 
	- Fresh installation and integration of components need to be done 
- Capacity planning for computing resources needs time, expertise and budgetary allocation 
	- Enterprises prepare for the worst, but the average demand is far less most of the time → resource wasteage and increases the recurring cost of business 
- Resource requirements of a system may increase or decrease from time to time 
- Some systems host applications and require round-the-clock availablity to fulfill business demands 

---
### Individual User’s Perspective 

- Procurement of computing systems is necessary to run software applications like text editor, image editor, programming, games, etc 
- Initial setup cost of computing infrastructure is far more than the software applications 
- Requirement analysis and procurement of hardware infrastructure are responsibility of the users 
	- Actual utilization of these resources depends on frequency of user access and the kind of software applications they run over it
- General users are often misguided and procure unnecessary volume / capacity of hardware resources  
	- Reduces ROI 
- Maintanance of the hardware infrastructure is the user’s responsibility 
	- Time, cost and the uncertainty are involved in the process 
- Non-utilization of procured systems results in wastage of resources 
- Software licensing cost needs separate budgetary allocation 
- Users are burdened with installation and critcal customization of software 
- Users need to have physical access to the system for using a personal computing system 
- After every few years, the hardware systems become obsolete and it becomes difficult to run newer softwares 
	- Users have no option but to replace the entire setup 

---
## Solution 

- IT service outsourcing 
	- but it does not address all the problems mentioned above 
- The problem remains the same just redirected to a different organization 
- Different teams will have different computing requirements and concers 
- Concers of the users of computing vary with the layers of their computing activities
