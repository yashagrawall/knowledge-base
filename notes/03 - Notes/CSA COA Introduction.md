# CSA COA Introduction

---
## Architecture

**Architecture** : Conceptual design and fundamental operational structure 

We define the Architecture of the whole Computer, especially the [[Processing Units or Processors#1. CPU|CPU]]
1. CPU design 
2. Instructions that the CPU will support 
3. Addressing Mode 
4. [[Data Format ]]

---
## Organization

**Organiztion** : Deals with the physical devices and their interconnections with a perspective of improving the performance 
1. I/O Organization 
2. Memory Organization 
3. Performance 

> Deciding the properties of the physical devices 
   How the devices communicate with each other
