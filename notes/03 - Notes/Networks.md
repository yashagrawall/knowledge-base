# Networks 

- Network : Set of devices (nodes) connected by communication links. 
- node : anything that can send and/or receive data generated by other nodes on the network. 

---
## Network Criteria

---
### Performance 

- transit time : amount of time required for a  message to travel from one device to another
- response time : elapsed time between an inquiry and a response 
- performance depends on : 
	- no. of users 
	- type of transmission medium 
	- capabilities of the connected hardware 
	- efficiency of the software 

#### Performance Evaluation Networking Metrics 

- Networking metrics for the evaluation of Performance 
	- Throughput (need more) : rate at which data is transferred through a system 
	- Delay (need less) 
- Often contradictory 
- If we try to send more data to the network, we may increase throughput, but we increase the delay because of traffic congestion in the network. 
	- Network has limited capacity 
	- more traffic → more delay 

---
### Reliability 

- Measured by :
	- accuracy of delivery 
	- the frequency of failure 
	- time taken to recover from a failure (MTTR : Mean time to recover/repair)
	- network’s robustness in a catastrophe
		- measures whether the network can continue to function or recover effectively during a major event 
		- catastrophe could be a major power failure, natural disasters, large scale equipment failure, etc.

---
### Security 

- protecting data from unauthorized access 
- protecting from damage and development 
- implementing policies and procedures for recovery from breaches and data losses
