# Floating Point Representation 

---
- It provides larger range of numbers with limited no. of bits 

The number is represented in format : 

| Sign | Exponent | Mantissa / Fraction |
| ---- | -------- | ------------------- |

- Mantissa is a sign normalized (implicit / explicit) fraction number 
- Exponent is stored in biased form → only unsignedvalue
