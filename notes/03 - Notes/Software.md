# Software

- Collection of Programs
- Computer software consists of the instructions and data that the computer manipulates to perform various data-processing tasks
- A sequence of instructions for the computer is called a program 
- The data that are manipulated by the program constitute the [[DBMS Basics#Data Base|Database]] 
- Two Types : 
	- [[#Application Software]]
	- [[#System Software]]

---
## Application Software

- According to Need/Utility 
- written to solve a particular problem

>[!example] Application Software
Games, Anti-Virus, MS-Office, Calculator, etc

---
## System Software
- Computer can't function without them
- make more effective use of the computer 
- Indispensable part of a computer system
- Function : Compensate for the differences that exist between user needs and the capability of the [[Hardware]]  

>[!example] System Software
[[Operating System]], Linker, Loader, Compiler, etc
