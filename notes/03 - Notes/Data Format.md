# Data Format 

---

- Binary Representation of Data Values 

## Type of Data : 

1. Numbers 
	1. Fixed Point Representation (generally not used for Float Type Values)
		1. Unsigned 
		2. Signed (Arithmetic Number)
			1. [[Sign Magnitude]] 
			2. [[1’s Complement]] 
			3. [[2’s Complement]] 
	2. Floating Point Representation 
		1. Single Precision
		2. Double Precision
2. Characters 
	1. ASCII (American Standard Code for Information Interchange)
	2. EBCDIC (Extended Binary Code Decimal Interchange Code) 
		- BCDIC is for Integers 
		- EBCDIC is for Characters
