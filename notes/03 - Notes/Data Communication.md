# Data Communication 

---
## [[Networks]] 

**Networks** : Data may be sent from one place to another 
**Networking** : Data Communication between remote parties, involving the connection of computers, media and networking devices.

#### Types of Networks
1. LANs (Local Area Networks) 
2. WANs (Wide Area Networks) 

Internet : Collection of LANs & WANs held together by collection of internetworking devices

### Data Communication 

- Data : information presented in whatever form is agreed upon by the parties creating and using the data
- Data Communication : exchange of data between two devices via some form of transmission medium such as a wire cable 

The effectiveness of a data communication system depends on 4 characteristics : 
1. Delivery : 
	1. The system must deliver data to the correct destination. 
	2. Data must  be received by and only by the intended device or user 
2. Accuracy : 
	1. The system must deliver the data accurately. 
	2. Data that have been altered in transmission and left uncorrected are unusable. 
3. Timeliness : 
	1. The system must deliver the data in a timely manner 
	2. Data delivered late are useless 
	3. In case of audio and Video → real time transmission : delivering data as they are produced, in the same order and without any significant delay 
4. Jitter : 
	1. Jitter : variation in the packet arrival time 
	2. Uneven delay in the delivery time of audio and video packets 

---
### 5 Components of Data Communication 

1. Message : 
	- the information / data to be communicated 
	- eg : text, numbers, pictures, audio, and video
2. Sender : 
	- The device that sends the message 
	- eg : computer, workstation, telephone handset, video camera, etc.
3. Receiver : 
	- The device that receives the message 
	- eg : computer, workstation, telephone handset, video camera, etc.
4. Transmission Medium 
	- The physical path by which the message travels from the sender to the receiver 
	- eg : twisted pair cable , coaxial cable , fiber optic cable , radio waves , etc.
5. Protocol 
	- Set of rules that govern data communication 
	- agreement between the communicating devices 
	- without  a protocol  two devices may be connected but not communicating
