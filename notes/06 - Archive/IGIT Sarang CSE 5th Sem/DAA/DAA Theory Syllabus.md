# Design and Analysis of Algorithm (PCCS4306)
**B.Tech Computer Science & Engineering — 5th Semester**  
**Course Credits**: 3 (3-0-0)  
**Department**: Computer Science Engineering & Applications, IGIT Sarang

---

## Course Objectives
Students should be able to:
1. Define algorithm formally and informally
2. Explain elementary and advanced data structures
3. Explain the different algorithms for solving typical problems
4. Describe the process of algorithm design and analysis
5. Explain the complexity of algorithms
6. Design recursive and non-recursive algorithms for, say, computing a Fibonacci number
7. Explain P, NP and NP-completeness

---

## Course Syllabus

### MODULE I (10 Hours)
- **Introduction**:
  - Role of Algorithms in Computing
  - Analyzing Algorithms
  - Designing Algorithms
  - Asymptotic Notations ($O, \Omega, \Theta, o, \omega$), Standard Notations and Common Functions
- **Advanced Data Structures**:
  - Linear vs. Non-linear Data Structures
- **Recurrences**:
  - Methods for Solving Recurrences: Substitution Method, Recursion Tree Method, Master Method

### MODULE II (10 Hours)
- **Hashing**:
  - Review of Hashing & Hash Functions
  - Collision Resolution Techniques in Hashing: Separate Chaining, Open Addressing (Linear Probing, Quadratic Probing, Double Hashing)
  - Rehashing & Extendible Hashing
- **Heap Structures**:
  - Min-Max Heap
  - Binomial Heaps
- **Search and Tree Structures**:
  - Binary Search Tree (BST)
  - AVL Tree
  - Priority Queue
  - Lower Bounds for Sorting

### MODULE III (12 Hours)
- **Divide and Conquer**:
  - Quick Sort, Merge Sort
  - Strassen’s Algorithm for Matrix Multiplication
- **Dynamic Programming**:
  - Longest Common Subsequence (LCS)
  - Floyd-Warshall Algorithm (All-Pairs Shortest Path)
  - Matrix Chain Multiplication
- **Greedy Algorithms**:
  - Single-Source Shortest Path (Dijkstra’s Algorithm)
  - Fractional Knapsack Problem
  - Minimum Cost Spanning Trees (Kruskal’s and Prim’s Algorithms)
  - Huffman Coding Algorithm
- **Geometric Algorithms**:
  - Convex Hulls
  - Segment Intersections
  - Closest Pair of Points
- **Internet and Network Flow Algorithms**:
  - Text Pattern Matching (Naive and Rabin-Karp Algorithms)
  - Flow Networks, Cuts, Ford-Fulkerson Method
- **Graph Algorithms**:
  - Breadth-First Search (BFS), Depth-First Search (DFS)
- **Backtracking & Branch and Bound**:
  - $n$-Queens Problem
  - Hamiltonian Circuit Problem
  - Subset Sum Problem
  - Branch and Bound
- **Discrete Fourier Transform (DFT)**:
  - DFT in Complex Field
  - DFT in Modulo Ring
  - Fast Fourier Transform (FFT) Algorithm

### MODULE IV (8 Hours)
- **Complexity Classes & NP-Completeness**:
  - Polynomial Time, Polynomial-Time Verification
  - NP-Completeness & Reducibility
  - NP-Completeness Proofs
  - Cook’s Theorem
- **Approximation Algorithms**:
  - Vertex Cover Problem
  - Traveling Salesperson Problem (TSP)
