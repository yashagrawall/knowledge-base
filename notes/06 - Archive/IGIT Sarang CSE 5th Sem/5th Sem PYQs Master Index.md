## 4. Key Exam Preparation Takeaways

1. **Top Numerical / Repetitive Exam Questions across 5th Sem:**
   - **CN:**
     - Shannon/Nyquist bit rate & signal levels calculation ($B = 2\text{ MHz}, \text{SNR} = 255 \implies C = 16\text{ Mbps}, L = 16$).
     - MLT-3 line coding transition state diagram for bit sequence `0101110110`.
     - CDMA Walsh code generation ($W_4$ from $W_1 = [-1]$ or $[+1]$).
     - Subnetting for 4 departments ($D_1=30, D_2=10, D_3=50, D_4=90$ hosts).
   - **DAA:**
     - Recurrences and Asymptotic proofs ($2n+10 = O(n)$, $f(n)=\Theta(g(n))$).
     - Huffman coding greedy tree for frequencies $a:45, b:13, c:12, d:16, e:9, f:5$.
     - Shortest path algorithms (Dijkstra single source, Floyd-Warshall all-pairs).
     - Ford-Fulkerson Max-Flow and Min-Cut capacity calculation.
     - String matching with Rabin-Karp and spurious hits analysis.
   - **MPMC:**
     - 8085 architecture block diagram and functional pin diagram (demultiplexing ALE, control bus).
     - Timing diagram for Opcode Fetch machine cycle and instruction `MVI B, 50H`.
     - 8086 BIU & EU block diagram, prefetch queue, real-mode address calculation ($\text{CS} \times 16 + \text{IP}$).
     - Interfacing chips: 8255 PPI operating modes (Mode 0, 1, 2) and 8251 USART architecture.
     - 8051 pin functions ($\overline{\text{PSEN}}, \text{XTAL}, \text{RST}$) and 4 parallel I/O port circuits.
   - **CSA:**
     - Booth's Algorithm for signed binary multiplication (`11001 × 10011` and `0111 × 1001`).
     - Cache memory mapping techniques (Direct, Associative, Set-Associative).
     - Pipeline hazards (Structural, Data, Control) and mitigation strategies.
     - Virtual memory mechanisms (Paging vs Segmentation) and memory interleaving.
     - Control sequencing for instruction execution (`ADD R4, R5, R6`).
   - **CC:**
     - Virtualization types (Hypervisor Type 1 vs Type 2, OS-level containerization vs Full emulation).
     - NIST cloud reference architecture, service models (IaaS, PaaS, SaaS), deployment models.
     - AWS core building blocks: EC2 instance types, S3 object storage immutability, SQS, SNS, SES messaging.
     - Google AppEngine runtime architecture and Windows Azure fundamentals.
