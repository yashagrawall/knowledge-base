# Cloud Computing (OECS6331)
**B.Tech Computer Science & Engineering — 5th Semester**  
**Course Credits**: 3 (3-0-0)  
**Department**: Computer Science Engineering & Applications, IGIT Sarang

---

## Course Objectives
This course gives students an insight into the basics of cloud computing along with virtualization. As one of the fastest growing domains, it provides students a solid foundational understanding of cloud delivery models, virtualization mechanisms, platform architectures, and enterprise migration strategies.

---

## Course Syllabus

### MODULE I (10 Hours)
- **Evolution of Computing Paradigms**:
  - Overview of Existing Hosting Platforms
  - Grid Computing, Utility Computing, Autonomic Computing
  - Dynamic Datacenter Alliance, Hosting and Outsourcing
- **Introduction to Cloud Computing**:
  - Definition, Characteristics, and Cloud Service Models (IaaS, PaaS, SaaS)
  - Workload Patterns for the Cloud
  - Big Data in the Cloud
  - IT as a Service (ITaaS)
  - Underlying Technologies Behind Cloud Computing (Virtualization, Hypervisors, Clustering, Multi-tenancy)

### MODULE II (10 Hours)
- **Classification of Cloud Implementations**:
  - Public, Private, Hybrid, and Community Clouds
- **Infrastructure as a Service (IaaS)**:
  - **Amazon Web Services (AWS)**:
    - Amazon Elastic Compute Cloud (EC2)
    - Amazon Simple Storage Service (S3)
    - Amazon Simple Queue Service (SQS)
  - **VMware vCloud**:
    - vCloud Architecture & IaaS Management
    - vCloud Express
- **Platform as a Service (PaaS)**:
  - **Google App Engine (GAE)**:
    - Architecture & Features
    - Java Runtime Environment

### MODULE III (10 Hours)
- **PaaS Implementations (Continued)**:
  - **Google App Engine (GAE)**:
    - Python Runtime Environment
    - Datastore & Development Workflow
  - **Windows Azure Platform (Microsoft Azure)**:
    - Windows Azure Core Architecture
    - SQL Azure
    - Windows Azure AppFabric
- **Software as a Service (SaaS) & Enterprise Platforms**:
  - **Salesforce.com (SaaS / PaaS)**:
    - Force.com Architecture
    - Force Database (Persistency Layer) & Enterprise Data Security
  - **Microsoft Office Live & LiveMesh.com**
  - **Google Apps (Google Workspace)**
- **Cloud Platform Analysis**:
  - Comparison of Cloud Computing Platforms
  - Common Architectural Building Blocks

### MODULE IV (8 Hours)
- **Cloud Security**:
  - Infrastructure Security: Network Level, Host Level, Application Level
  - Data Security: Data-in-Transit, Data-at-Rest, Encryption & Key Management
  - Identity and Access Management (IAM): Access Control, Single Sign-On (SSO)
  - Privacy and Data Protection in Cloud Environments
  - Audit and Compliance: Regulatory Requirements, Risk Management, Security Audits
