# Cloud Computing — Regular Examination 2022–23

> **Course**: Cloud Computing (OE-II / OECS6331)  
> **Programme**: B.Tech (All Branches) — 5th Semester  
> **Time**: 03 Hours | **Maximum Marks**: 60  
> **Instructions**: Answer Question No.1 which is compulsory and any five from the rest. The figures in the right-hand margin indicate marks.

## [[CC Theory Syllabus]]

- **Module 1**: Cloud Architecture, NIST Classification, Computing Paradigms.
- **Module 2**: Virtualization Layers (Guest, Host, Hypervisor), Emulation.
- **Module 3**: AWS Core Services (EC2, S3, SQS, SNS, SES, VPC).
- **Module 4**: Google AppEngine, Microsoft Azure, Cloud Security, Auditing, Sandboxing.
