# Computer System Architecture — Regular Examination 2023–24

> **Course**: Computer System Architecture (PECS5301)  
> **Programme**: B.Tech CSE — 5th Semester  
> **Time**: 03 Hours | **Maximum Marks**: 60  
> **Instructions**: Answer Question No.1 which is compulsory and any five from the rest. The figures in the right-hand margin indicate marks.

---

## [[CSA Theory Syllabus]]

- **Module 1**: Arithmetic (Booth's Algorithm), Processor Performance, Flynn's Classification.
- **Module 2**: Control Unit Design, Single-Bus Datapath, Control Sequencing.
- **Module 3**: Memory Hierarchy, Cache Mapping, Memory Interleaving, Virtual Memory.
- **Module 4**: Pipelining, Hazards, DLX Pipeline Stages, Vector/Array Processors.
