# Computer System Architecture — Regular Examination 2022–23

> **Course**: Computer System Architecture (PECS5301)  
> **Programme**: B.Tech CSE — 5th Semester  
> **Time**: 03 Hours | **Maximum Marks**: 60  
> **Instructions**: Answer Question No.1 which is compulsory and any five from the rest. The figures in the right-hand margin indicate marks.

---

## [[CSA Theory Syllabus]]

- **Module 1**: Binary Arithmetic, Booth's Algorithm, Floating Point Arithmetic.
- **Module 2**: Instruction Cycle, Control Unit (Microprogrammed vs Hardwired).
- **Module 3**: Memory Organization, Associative Memory, Virtual Memory.
- **Module 4**: Pipelining Characteristics, I/O Organization.
