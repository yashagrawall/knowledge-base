# Computer System Architecture — Regular Examination 2024–25

> **Course**: Computer System Architecture (PECS5301)  
> **Programme**: B.Tech CSE — 5th Semester  
> **Time**: 03 Hours | **Maximum Marks**: 60  
> **Instructions**: Answer Question number 1 which is compulsory and any five from the rest. The figures in the right-hand margin indicate marks.

---

## [[CSA Theory Syllabus]]

- **Module 1**: Computer Performance, Instruction Formats, Addressing Modes.
- **Module 2**: CPU Design, Datapath, Control Unit (Hardwired vs Microprogrammed), Control Sequencing.
- **Module 3**: Memory Hierarchy, Cache Mapping, Virtual Memory, Memory Interleaving.
- **Module 4**: Pipelining, Pipeline Hazards, Parallelism.
